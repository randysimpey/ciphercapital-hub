FAQ

Before you run a scan.

Is repository code stored?

The site currently describes repository content as being cloned to temporary storage for scanning and deleted after the scan. This should remain true in the actual backend before making the claim a production guarantee.

Does the free scan support private repositories?

The current free workflow is for public repositories. Private repository support is positioned for paid workflows.

How long does a scan take?

Most repositories are intended to finish quickly, but scan time depends on repository size and the checks enabled.

What tools power the scan?

Gitleaks is used for secret detection and Trivy for dependency and infrastructure scanning. CipherCapital's value is the product layer around the evidence.

Is CipherCapital a security certification?

No. A scan is a security assessment aid, not a guarantee that an application is secure or compliant.
