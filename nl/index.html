Wat ik doe

CipherCapital ontleedt real-world security-kwetsbaarheden — hardcoded secrets, verouderde dependencies, verkeerd geconfigureerde infrastructuur, blootgestelde API's — met praktische walkthroughs die je zelf kunt volgen.

Naast de video's bouw ik aan SecurityAuditAI: een tool die precies de checks automatiseert die in elke tutorial aan bod komen, zodat je dezelfde problemen in je eigen codebase kunt opsporen in minder dan twee minuten — in plaats van er handmatig naar te zoeken.

Wat er gecontroleerd wordt

Secrets detection

Hardcoded API-keys, wachtwoorden, SSH-keys en tokens — ook die verstopt zitten in oude commits, niet alleen de huidige code.

Dependency vulnerabilities

Verouderde of kwetsbare open-source packages, gecontroleerd tegen de OWASP Top 10 en bekende CVE-databases.

Infrastructure as Code

Misconfiguraties in Dockerfiles, Kubernetes-manifests en Terraform — het soort fouten dat stilletjes een deur open laat staan.

API security

Niet inbegrepen in deze gratis statische scan — dat vereist een levende endpoint, niet alleen een repo. Beschikbaar als handmatige review, of automatisch bij SecurityAuditAI Pro.

Vragen

Wordt mijn code ergens opgeslagen?

Nee. De repo wordt tijdelijk gekloond voor de scan, en direct daarna verwijderd. Er blijft niets op onze servers achter.

Werkt dit ook op private repo's?

Niet in de gratis versie — die scant momenteel alleen publieke repo's. Ondersteuning voor private repo's zit bij de betaalde tiers.

Hoe lang duurt een scan?

Meestal minder dan 2 minuten voor de meeste repo's. Grotere repo's (dichter bij de limiet van 300MB) kunnen iets langer duren.

Wat telt als een "kwetsbaarheid"?

Bekende, publiek gerapporteerde problemen in je dependencies (getraceerd via CVE-ID), plus veelvoorkomende misconfiguratie-patronen in IaC-bestanden — geen gok, maar een match tegen gevestigde databases.
