What this is

CipherCapital publishes cybersecurity tutorials. SecurityAuditAI is a scanning service, built by the same person, that checks a repository for exposed secrets, vulnerable dependencies and infrastructure-as-code misconfigurations using Gitleaks and Trivy. Both are operated by ICT Support By Randy, a sole proprietorship based in Amsterdam, the Netherlands.

The free scan

  • Public GitHub repositories only.
  • One free scan a month per person.
  • The repository is cloned temporarily to run the scan, then the clone is deleted. It is not kept, reused, or used to train anything.
  • Free scans are currently run manually, so turnaround depends on the queue rather than a server.

Paid plans and assessments

  • Pro, $49 a month — unlimited scans on up to five repositories, private repository access, fix snippets.
  • Business, $199 a month — scan on every commit through CI/CD, team access, SOC 2 and GDPR-ready reporting.
  • Security assessment, from €199 — a one-off manual review, delivered as a written report.
  • Deep assessment, priced per scope — agreed in writing after a scoping call before any work starts.

Subscriptions are billed monthly through Stripe and can be cancelled at any time from your billing portal. Cancelling stops the next cycle; a period already billed and running is not refunded pro rata. Assessments are quoted and agreed before work begins.

What a scan is, and is not

Scan results are produced automatically by open-source tools against public vulnerability databases. They are a useful first pass. They are not a professional security audit, not a penetration test, and not a guarantee that your code is safe. A static scan cannot find business logic flaws, broken access control, or anything that only appears against a running system. Treat findings as a starting point, never as a certification.

Acceptable use

Do not submit repositories you have no right to inspect. Do not attempt to disrupt, overload, or reverse-engineer the scanning pipeline. Access can be suspended for abuse of the free tier or of the service generally.
